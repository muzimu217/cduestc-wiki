# 入党流程

想入党，最重要的两件事：**尽早交申请书**（排队是真的），以及**每个阶段都别掉链子**（学业、群众基础、材料）。

## 完整流程总览

学校官方培训中对学生入党路径的表述为：

> 提交入党申请书 → 转为入党积极分子 → 积极分子培养考察、参与党课学习 → 确定发展对象 → 政治审查、集中培训 → 预备党员 → 预备期培养教育 → 转正成为正式党员

从递交申请书到成为正式党员，通常需要 **两年半到三年以上**，大一大二递交申请是常态。

## 分阶段说明

### 1. 递交入党申请书

- 条件：年满 18 周岁的在校学生（团员/群众均可）；
- 写法：手写，标题《入党申请书》，正文包括对党的认识、入党动机、本人成长经历、家庭主要成员及社会关系情况等，落款签名并注明日期；
- 交给谁：交给辅导员或所在学院学生党支部（党总支），开学初、学期中都可以交。

::: tip
“入党动机”不要抄模板，结合自己真实经历写，后续谈话会被问到。写完记得主动和辅导员说一声，确保被登记。
:::

### 2. 入党积极分子（“推优”）

- 共青团员一般须经团支部“推优”产生，支部委员会研究确定入党积极分子并公示；
- 确定后指定 1—2 名正式党员作培养联系人，开始**一年以上**的培养考察，定期递交思想汇报（一般每季度一篇）；
- 参加学校党校“入党积极分子培训班”并结业（各学院党总支轮流办班，如工学院党校培训班已举办多期）。

### 3. 发展对象

- 入党积极分子经一年以上培养考察、听取培养联系人和党内外群众意见后，可确定为发展对象；
- 部分学院有量化考核办法，例如商学院制定了《学生党员、预备党员、发展对象、入党积极分子考核办法》，从硬指标（学业成绩等）、软指标（表现评议）和笔试成绩综合排序择优；
- 发展对象须接受**政治审查**（本人及直系亲属）和**短期集中培训**（一般不少于 3 天或 24 个学时）。

### 4. 预备党员

- 支部大会讨论接收，采取无记名投票方式表决，获得应到会有表决权党员半数以上同意方能通过；上级党委审批后成为预备党员；
- 预备期**一年**，从支部大会通过之日算起，期间继续接受教育考察、递交思想汇报。

### 5. 转正

- 预备期满，本人主动提交《转正申请书》；
- 支部大会讨论表决通过后按期转正；表现不佳可延长预备期（不超过一年）。

## 常见问题

- **挂科/处分影响入党吗？** 影响很大。各阶段审核都会看学业成绩，受纪律处分会中断发展进程；入党对成绩的要求普遍高于奖学金底线。
- **不是团员可以入党吗？** 可以，年满 18 周岁即可申请，但团员身份在“推优”环节更顺，大学期间入团窗口变少，高三前未入团的同学尽早向辅导员确认路径。
- **在哪里看进度？** 关注学院党支部通知和“共产党员网”学习要求；全国党员发展各环节材料会归入本人档案。
