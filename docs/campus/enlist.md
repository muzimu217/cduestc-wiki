# 征兵入伍

大学生入伍是“学费国家买单 + 退役一大波升学就业优惠”的组合。本校征兵归口在**就业创业指导中心征兵工作办公室**（石老师，028-87828593），学费资助办理在**学工处资助中心**。

## 什么时候能入伍

全国征兵每年两次（时间以全国征兵网为准）：

- **上半年**：约 1—2 月报名、3 月入伍；
- **下半年**：约 7—8 月报名、9 月入伍（与毕业季衔接，应届生主力批次）。

在校生、应届毕业生、往届毕业生均可应征，登录**全国征兵网**（www.gfbzb.gov.cn）登记报名，应征地可选学校所在地（成都/什邡）或户籍地。

## 入伍能拿什么：学费补偿 / 贷款代偿

入伍服兵役（含义务兵、直接招收为士官、消防救援）可享：

- **学费补偿**：在校期间实际缴纳的学费由国家补偿，本专科每年最高 **20000 元**；
- **国家助学贷款代偿**：办过助学贷款的，贷款由国家代偿（含在校利息）。

### 办理流程（学校就业创业指导中心官方口径）

::: info 关键提醒
**入伍成功三个月后办理**。学校每年 **9 月集中受理**，材料录入审核后一般 **12 月底或次年 1 月初到账**。
:::

1. 登录全国征兵网在线填写并打印《应征入伍服兵役高等学校学生国家教育资助申请表》**一式两份**（手写、复印无效）；
   - 学校地址统一填：四川省成都市高新西区百叶路 1 号，邮编 611731；
   - “实交金额”只填学费，补贴金额按国家标准填写；
2. **三步盖章**：① 入伍地武装部盖章 → ② 学校收费中心（成都校区实验大楼一楼结算中心）核实学费后盖章 → ③ 交学工处资助中心于老师（国腾 3 号楼 4 楼）；
3. 基本材料：申请表（盖章）两份、《入伍通知书》复印件、本人银行卡复印件（备注开户支行）；收款人非本人还需授权委托书原件 + 关系证明。

办理贷款代偿另需：借款合同复印件、本人签字的《一次性偿还贷款计划书》；往届毕业生还需已还本息的银行凭证。

- 学费减免（资助）咨询：028-87828640，咨询 QQ 群：281970501。

## 退役复学 / 退役入学：学费减免

- **退役复学**（在校生入伍后回校）：凭《申请表Ⅱ》（安置地县级征兵办盖章）+《退出现役证书》复印件申请学费减免；
- **退役入学**（考上大学前当过兵的新生）：《申请表Ⅱ》须同时加盖征兵办和退役军人事务部门两个章。

## 退役后的升学优惠

- **免试专升本**：四川普通专升本对退役大学生士兵实行免试录取（计划单列），细则见[专升本](/study/upgrade)；
- **考研加分**：退役后 3 年内参加全国硕士研究生招生考试，初试总分加 10 分，同等条件下优先录取；
- **专项计划**：教育部设“退役大学生士兵”专项硕士研究生招生计划，单独划线录取；
- **复学转专业**：退役复学时可按学校规定申请转专业（放宽条件），具体咨询学工处与教务处。

## 当兵两年值不值（在读视角）

- 经济账：学费补偿/代偿 + 服役津贴 + 退役金 + 地方奖励，两年总收入对普通家庭相当可观；
- 学业账：保留学籍，退役后复学有学费减免 + 升学加分/免试；
- 代价：比同学晚毕业两年，技术类岗位手感会生疏，退役后需要一段追赶期。

想清楚再决定，但**信息要拿全**：校内咨询征兵办石老师 028-87828593，全国政策以“全国征兵网”和学校当年通知为准。
