# 就业与实习

求职是信息战 + 时间战。这一页讲**时间线、三方协议/应届生身份这些规则坑**，以及校内能用到的人和钱。

## 校招时间线

| 时间 | 事项 |
|------|------|
| 大三上—寒假 | 开始攒实习：日常实习、寒暑假实习投递 |
| 大三下 3—5 月 | 暑期实习招聘（大厂暑期实习≈秋招预录取，尽量冲） |
| 大三暑假 | 实习，产出可写进简历的项目/数据 |
| 大四上 9—11 月 | **秋招**（校招主力，岗位量最大） |
| 大四下 3—5 月 | **春招**（补录为主，岗位少于秋招，别指望春招兜底） |
| 毕业学年全年 | 双选会、宣讲会，关注学校就业创业指导中心发布 |

学校就业创业指导中心会持续发布招聘信息、校园宣讲和双选会安排，就业管理办王老师负责双选会/宣讲会，邓老师负责实习实训与校企合作，胡老师负责就业困难帮扶（含各类补贴）。联系方式见[职能部门](/campus/connect)。

## 三方协议：签字前必读

**三方协议**全称《全国普通高等学校毕业生就业协议书》，是毕业生、用人单位、学校三方就就业意向达成的书面协议，**不是劳动合同**，签了它你的应届生“去向”就登记了。

签约前逐条检查：

1. **违约金**：常见 3000—5000 元，部分单位写得很高，可以协商，白纸黑字确认；
2. **备注栏**：把口头承诺（岗位、地点、薪资构成、解约条件）写进备注，这是唯一能保护你的地方；
3. **解约代价**：想毁约需单位出具解约函才能换新三方，流程可能拖很久——秋招早期先拿保底可以，但要想清楚；
4. 两方协议（单位与个人双方）同样有约束力，违约条款照看不误。

::: warning 2023 年起的变化
国家已取消就业报到证，档案转递不再以报到证为前提。毕业去向登记通过学校就业系统进行，毕业前按学校通知完成登记即可。
:::

## 应届生身份怎么保住

应届生身份关系校招资格、部分公务员/事业编岗位、落户补贴等。认定口径各地各单位不完全一致，通用原则：

- 毕业当年 + 择业期内（不少地区为 2 年）未落实工作单位（未缴社保）的，可按应届生对待；
- **毕业后谨慎缴纳社保**：Gap 期打工交了社保，可能影响“未落实工作”认定；
- 考公考编以**招录公告原文**为准，不同岗位口径差异大；
- 升学（读研）不损失应届身份，研究生毕业时仍是应届生。

## 档案去哪

- 就业单位有人事档案管理权限（国企、事业单位、机关）→ 转单位；
- 民企/外企等无档案权限 → 转单位委托的公共就业人才服务机构，或生源地人才中心；
- 暂不就业/升学失败 → 一般转回生源地人才中心保管（免费），档案严禁自己拿着。

毕业季按学校就业处通知在系统里确认去向即可，档案疑问找征兵工作办公室石老师（也管档案查询）或就业管理办。

## 校企合作与内推资源

计算机学院长期合作企业包括华为（成研所）、奇安信、国信安、工业信息安全（四川）创新中心等；工学院有大批电子信息类校企实训基地。教研室、实验室老师手里常有内推名额，主动问一句的成本很低。

外部渠道：教育部“国家大学生就业服务平台”（原 24365 校园网络招聘服务）、四川省人社厅招聘平台，以及各公司官网校招页。

## 能领的钱：一次性求职补贴

成都校区毕业生（以 2026 届政策为例，依据成人社〔2024〕83 号）符合下列任一情形可申领**每人 1500 元**一次性求职补贴：

- 低保家庭毕业生；零就业家庭毕业生；防止返贫监测对象家庭毕业生；特困人员中的毕业生；残疾毕业生；获得国家助学贷款的毕业生。

每年 9 月左右就业处发申领通知，逾期视为放弃。咨询：就业创业指导中心（北区 3 号楼 413）。
